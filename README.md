# Adam Wood Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my projects, technical skills, and journey as a Computer Science & Economics student.

## Overview

This portfolio website serves as a central place to showcase my programming projects, skills, and experience. It was created as part of my web development learning phase to practice building responsive websites using core frontend technologies.

## Features

- Responsive design for desktop and mobile devices
- About section introducing my background and interests
- Skills section highlighting technical abilities
- Projects section showcasing completed software projects
- Contact links for professional networking

## Technologies Used

- HTML
- CSS
- JavaScript
- Git & GitHub

## Projects Featured
